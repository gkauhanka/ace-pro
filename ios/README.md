# Ace Pro iOS prototype

This is a SwiftUI UX prototype backed entirely by `MockData.swift`. It covers the initial product loop:

1. See the highest-priority post-match focus.
2. Open a match report ranked by impact.
3. Inspect the evidence clips behind an insight.
4. Verify or correct a mocked AI detection.
5. Add a new match through a mocked upload flow.

## Run

Open the included project from this directory:

```sh
open AcePro.xcodeproj
```

Choose any iPhone simulator running iOS 17 or newer. No backend, account, API key, or package installation is required.

`project.yml` is also included as the reproducible XcodeGen project definition if you prefer to regenerate the project.
