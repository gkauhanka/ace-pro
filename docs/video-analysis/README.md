# Video Analysis Technical Specifications

This directory is the implementation handoff for the Ace Pro video-analysis pipeline described by [ADR-0001](../adr/0001-hybrid-evidence-backed-video-analysis.md). The documents specify component boundaries and contracts; they do not claim that the proposed models have already met the required accuracy.

## Product objective

Turn a completed tennis-match upload into a small number of prioritized, evidence-backed patterns that a player or coach can review, correct, and use to choose a practice focus.

The first vertical slice is deliberately narrow:

> For a fixed-camera singles match, identify the player’s backhand returns, classify the first bounce as short or deep, associate each return with the point outcome, and calculate the difference in loss rate.

## System invariants

All components must preserve these rules:

- Original uploads are immutable.
- Jobs are idempotent by video and pipeline version.
- Timestamps use integer milliseconds relative to the original video timeline.
- Derived artifacts identify their source video, job, producer, and version.
- Machine predictions are immutable; corrections are separate records.
- Numeric insights are calculated by versioned code, never generated by prose models.
- An insight cannot be published without evidence event IDs.
- Low-quality footage disables unsupported capabilities rather than producing confident guesses.
- Deleting a video must ultimately delete its derived media and analysis records according to the product retention policy.

## Terminology

- **Original:** user-uploaded MOV or MP4 object.
- **Analysis proxy:** normalized media used by inference workers.
- **Artifact:** versioned file or structured output produced by a pipeline component.
- **Prediction:** immutable machine-produced observation.
- **Effective event:** prediction plus the latest accepted correction overlay.
- **Pattern:** deterministic aggregate over effective events.
- **Insight:** a publishable pattern with rank, evidence, confidence, and presentation text.
- **Capability:** an analysis type such as court calibration, return depth, or point outcome.
