# Architecture Decision Records

Architecture Decision Records (ADRs) capture decisions that affect multiple Ace Pro components or are expensive to reverse. Each record describes its context, decision, consequences, and the evidence that could cause the decision to be revisited.

## Status definitions

- **Proposed:** ready for technical validation but not yet confirmed by implementation evidence.
- **Accepted:** validated sufficiently to guide implementation.
- **Superseded:** replaced by a newer ADR.
- **Rejected:** considered but deliberately not adopted.
