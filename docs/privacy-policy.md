# Ace Pro Privacy Policy

Effective date: September 21, 2026

Ace Pro is a private, on-device tennis video review application. This policy describes the release version of the native iOS application.

## Information Ace Pro handles

Ace Pro stores the following information locally inside the app on the user's device:

- video files the user explicitly selects from Photos or Files;
- session titles, dates, session type, and selected review focus;
- measurements produced by Apple Vision while analysis is running; and
- observations written by the user.

Imported video copies are stored in protected application storage and excluded from device backups. Analysis measurements are processed on the device, remain in memory while the analysis screen is open, and are not uploaded by Ace Pro.

## Information Ace Pro collects

Ace Pro does not create user accounts, collect personal information, upload videos, use third-party analytics, display advertising, track users across apps or websites, or sell data. The release application does not connect to an Ace Pro server.

The user may choose to open the public Ace Pro support page in a web browser. GitHub then processes that visit under GitHub's own privacy terms. Users should not include private video or personal information in a public support request.

## Apple services

On supported devices, the user may ask Apple Intelligence to describe numeric measurements produced by the on-device analysis. The request uses Apple's on-device Foundation Models framework. Ace Pro does not send the original video to a language-model provider.

Selecting a video from an iCloud Photos library may cause Apple's system photo picker to download the selected original. That transfer is performed by Apple's service, not by Ace Pro.

## Retention and deletion

Data remains on the device until the user deletes an individual session, chooses **Delete all app data** in Settings, or removes the application. Deleting an Ace Pro copy does not delete the original video from Photos or Files.

Ace Pro has no server-side copy to recover after deletion.

## Children

Ace Pro does not knowingly collect personal information from children or any other users.

## Changes

If a future version introduces network services or new data practices, this policy and the App Store privacy disclosures will be updated before that version is released.
